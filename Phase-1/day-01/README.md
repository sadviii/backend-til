# Day 1 — Syntax & Control Flow

## Topics Covered

### 1. Variables & Data Types

Learned how to create variables and work with `int`, `float`, `str`, and `bool` data types.

### 2. Input & Type Casting

Learned how to take user input using `input()` and convert values using type casting such as `int()`.

### 3. Operators

Learned arithmetic operators such as `+`, `-`, `*`, `/`, `//`, `%`, and `**`, along with comparison operators.

### 4. Conditional Statements

Learned to use `if`, `elif`, and `else` to make decisions based on conditions.

### 5. For & While Loops

Learned how to repeat code using `for` and `while` loops and how `range()` works.

### 6. Break & Continue

Learned how `break` stops a loop and `continue` skips the current iteration.

### 7. Nested Loops

Learned how to use a loop inside another loop and practiced creating simple patterns.

### 8. Variable Scope

Learned the difference between local and global variables and how scope affects variable access.

## Hands-on Practice

* Positive, Negative & Zero checker
* Even & Odd checker
* Age classification
* Sum of numbers using loops
* Nested loop patterns
* Variable scope examples
* Number Analyzer mini program

## Key Takeaway

Built a foundation in Python syntax and control flow and practiced applying these concepts to solve basic programming problems.

## Competency

Completed a Blank File–style console application using variables, conditions, loops, type casting, operators, and basic problem-solving.
