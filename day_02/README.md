
# Day 2 — Object-Oriented Programming (OOP)

## Topics Covered

### 1. Classes and Objects
Learned that a class is a blueprint for creating objects.
Objects are instances of a class that contain their own data and behavior.

### 2. `__init__()` and `self`
Learned how `__init__()` initializes an object's attributes when it is created.
`self` refers to the current object.

### 3. Attributes and Methods
Learned about instance and class attributes and how methods define object behavior.
Also practiced instance, class, and static methods.

### 4. Inheritance
Learned how a child class can reuse attributes and methods from a parent class.
Inheritance represents an **IS-A** relationship.

### 5. Method Overriding
Learned how a child class can provide its own implementation of a parent method.
The child's version takes priority over the inherited version.

### 6. Polymorphism
Learned how the same method can produce different behavior depending on the object.
Also practiced polymorphism through duck typing.

### 7. Encapsulation
Learned how to keep data and related methods together while controlling access to internal data.
Practiced private attributes and controlled methods.

### 8. Abstraction
Learned how to hide unnecessary implementation details and expose only essential functionality.
Practiced abstract classes and abstract methods.

### 9. Composition
Learned how one class can contain or use an object of another class.
Composition represents a **HAS-A** relationship.

### 10. Multiple Inheritance and MRO
Learned how a class can inherit from multiple parent classes.
MRO determines the order Python follows when searching for methods.

### 11. Dunder Methods
Learned how special methods such as `__str__()`, `__len__()`, and `__eq__()` customize object behavior.
Practiced using dunder methods with Python's built-in operations.

### 12. Properties
Learned how `@property` provides controlled access to attributes.
Practiced setters to validate and control changes to attribute values.

### 13. SOLID Principles
Learned the five SOLID principles for designing maintainable and flexible OOP code.
Covered SRP, OCP, LSP, ISP, and DIP at a basic level.

## Hands-on Practice

- Created classes and objects
- Practiced `__init__()` and `self`
- Practiced instance, class, and static methods
- Implemented inheritance and method overriding
- Practiced polymorphism and duck typing
- Implemented encapsulation and abstraction
- Practiced composition and multiple inheritance
- Worked with MRO and dunder methods
- Used `@property` and setters
- Built a Library Management System from a blank file

## Key Takeaways

- `self` → current object
- `cls` → current class
- Inheritance → **IS-A**
- Composition → **HAS-A**
- Encapsulation → controls access to data
- Abstraction → hides implementation details
- Polymorphism → same interface, different behavior
